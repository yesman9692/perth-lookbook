## 만점 61점 = 자동 6항목(33) + 판정 8항목(28)

### 자동 계산 (perth_score.py, 환각 없음)

| 항목 | 만점 | 공식 |
|---|---|---|
| **가격** | 10 | `3 + (700−가격)/40` ($500=8, $600=5.5, $700=3). 절대가격 — 통근↔가격 상쇄로 A존 이중우대 차단 |
| **통근** | 10 | `10 − 통근분/10 − 환승수 − (버스면 1) − 역도보m/300`. 하한 0 (대중교통만) |
| **자전거** | 5 | 독립 항목. 10분 이하 5 / 10분 초과 1분당 −0.1 / 30분 초과 0 |
| **편의** | 5 | `amenity_profile` 출력 파싱. TIER base: A=5·B=3.5·C=2·D=0.5. 도보 패널티: `−min(base, 최근접m/100×0.5)`. 하한 0. amenity 없으면 0 |
| **소음** | 2 | micro noise: **낮음·보통 2** / 약간·높음 1 / 심함 0 |
| **주차** | 1 | 1대 이상 1 / 없음 0 |

> **편의 TIER 기준** (perth_commute.amenity_profile): A = 슈퍼마켓 600m내 + 음식/카페 등 unique ≥10 / B = 슈퍼마켓 600m내 / C = 슈퍼마켓 없고 convenience_store 있음 / D = 600m내 없음

### 사진·광고 판정 (채점 서브에이전트, 점수마다 근거 필수)

| 항목 | 만점 | 기준 |
|---|---|---|
| **인테리어** | 5 | 톤·밝기 0-3.5 + 마감 0-1.5. 합산 0-5. 밝고 개방감 있으면 높음, 어둡고 낡으면 낮음. ⚠️ 가상스테이징에 속지 말고 주방·욕실 실제 마감으로 판정 |
| **카펫** | 5 | BARE(전체 맨바닥) 5 / MIX(일부 카펫) 3.5 / CARP(밝고 깨끗한 카펫) 2.5 / CARP(짙음·오염·낡음) 1.5 |
| **detached** | 5 | 완전분리 villa+전용마당 5 / 전용마당+사생활우려 4 / 마당+집붙음 3 / 1층전용마당 2 / 발코니만 1 / 없음 0 |
| **감성** | 1 | 외관 특출 또는 뷰(시티/리버, **명확할 때만**) 중 하나라도 있으면 1. 흐릿한 교외 전망은 0 |
| **안전** | 2 | 보안게이트/gated 2 / 보통(일반 잠금) 1 / 우려(두꺼운 쇠창살·burglar bars 등 우범 신호) 0 |
| **수납** | 3 | 전용런드리+창고/팬트리 3 / 전용런드리만 2 / 빌트인워드롭만 1 / 없음 0 |
| **동네** | 2 | 예쁨(leafy·강변 확립 동네 — West Leederville·Mt Lawley·South Perth·Como급) 2 / 보통(모난 거 없음) 1 / 우범(Armadale·Maddington·Gosnells 등) 0 |
| **면적** | 5 | **실내 면적만** (마당·파티오는 detached 항목 — 이중계산 금지). 넓음 5 / 표준 4 / 보통 3 / 작음 2 / 협소 1. 광고 m² 우선, 없으면 실내 사진 추정 |

> **인테리어 interior_parts 2성분**: `[["밝기·개방감", 점수(0-3.5)], ["마감 품질", 점수(0-1.5)]]` 형태로 verdicts에 포함.

## 🚫 탈락 조건 (3가지)
- 공용 세탁실 (communal laundry)
- 6개월 이하 단기계약 ("6 month"/"3 month"/"short term")
- 펫 키운 게 명확한데 카펫 (불명확하면 탈락 X)

## ⚠️ 주관 축 오류 주의 (사용자가 매번 잡아냄)
**인테리어·감성·뷰는 정답지가 없어 단일패스 정밀점수에 환원불가 오류 바닥이 있음.** 사진 전수(일부만 보지 말 것), 가상스테이징↔실제마감 구분, 뷰는 시티/리버 명확할 때만. 가격·통근·편의·주차·소음(자동)과 floor·detached(검증가능)는 신뢰. 사용자가 최종 검증자.

## 채점 서브에이전트 프롬프트 템플릿

아래 8항목을 verdicts.json의 해당 매물 객체에 기록한다. **출력 전부 한국어. 매물 영어 문구는 한국어 의역 — 영어 원문 인용 금지.**

```json
{
  "interior": <0-5 소수점 1자리>,
  "interior_reason": "<한국어 한 줄 근거>",
  "interior_parts": [["밝기·개방감", <0-3.5>], ["마감 품질", <0-1.5>]],

  "carpet": <1.5 | 2.5 | 3.5 | 5>,
  "carpet_reason": "<BARE/MIX/CARP밝/CARP짙 판정 근거 한 줄>",
  "carpet_parts": [["카펫 판정", <점수>]],

  "detached": <0-5 정수>,
  "detached_reason": "<구조 설명 한 줄>",
  "detached_parts": [["분리도", <점수>]],

  "emotion": <0 | 1>,
  "emotion_reason": "<감성 요소 설명 또는 '없음'>",
  "emotion_parts": [["감성", <점수>]],

  "safety": <0 | 1 | 2>,
  "safety_reason": "<보안 요소 설명 한 줄>",
  "safety_parts": [["안전", <점수>]],

  "storage": <0-3 정수>,
  "storage_reason": "<수납 구성 한 줄>",
  "storage_parts": [["수납", <점수>]],

  "hood": <0 | 1 | 2>,
  "hood_reason": "<동네 분위기 한 줄>",
  "hood_parts": [["동네", <점수>]],

  "area": <1-5 정수>,
  "area_reason": "<면적 추정 근거 한 줄>",
  "area_parts": [["면적", <점수>]],

  "oneliner": "<매물 전체 한 줄 평 — 한국어>",
  "disqualify": <true | false>
}
```

### 채점 서브에이전트 운용
- 입력 = `score_input.json`(floor/condition/vibe/micro/description/imgs) + `hood_input.json`(+analysis)
- amenity 필드는 manifest에서 자동 읽음 (commute 서브에이전트가 채운 값)
- 9건씩 배치, **백그라운드** 병렬 (`feedback_subagent_background`)
- 출력 = 각 항목 점수 + `_reason` 한 줄 + `_parts` 분해 리스트 + oneliner. 근거 없는 점수 금지
- 검증 = floor 교차검증 + UNSURE/충돌/이상치만 Claude 직접 사진 확인
- 점수차 1-2점은 동급
