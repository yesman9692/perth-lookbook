## 만점 59점 = 자동 6항목(33) + 판정 8항목(26)

### 자동 계산 (perth_score.py, 환각 없음)

| 항목 | 만점 | 공식 |
|---|---|---|
| **가격** | 10 | `3 + (700−가격)/40` ($500=8, $600=5.5, $700=3). 절대가격 — 통근↔가격 상쇄로 A존 이중우대 차단 |
| **통근** | 10 | `10 − 통근분/10 − 환승수 − (버스면 1) − 역도보m/300`. 하한 0 (대중교통만) |
| **자전거** | 5 | 독립 항목. 10분 이하 5 / 10분 초과 1분당 −0.1 / 30분 초과 0 |
| **편의** | 5 | `amenity_profile` 출력 파싱. TIER base: A=5·B=3.5·C=2·D=0.5. 도보 패널티: `−min(base, 최근접m/100×0.1)` (v4: 0.5→0.1). 하한 0. amenity 없으면 0 |
| **소음** | 2 | micro noise: **낮음·보통 2** / 약간·높음 1 / 심함 0 |
| **주차** | 1 | 1대 이상 1 / 없음 0 |

> **편의 TIER 기준** (perth_commute.amenity_profile): A = 슈퍼마켓 600m내 + 음식/카페 등 unique ≥10 / B = 슈퍼마켓 600m내 / C = 슈퍼마켓 없고 convenience_store 있음 / D = 600m내 없음

> **인테리어 interior_parts 2성분 (v4 B-full)**: `[["밝기·개방감", 점수(0-3.5), "근거"], ["마감 품질", 점수(0-1.5), "근거"]]` — 성분별 근거 포함(3-tuple). 카드가 성분별 막대+기준+근거로 표시. 근거 없는 2-tuple이면 카드는 합본 reason으로 폴백(B-lite). **향후 채점은 항상 3-tuple(B-full).**

## ⚠️ 주관 축 오류 주의 (사용자가 매번 잡아냄)
**인테리어·감성·뷰는 정답지가 없어 단일패스 정밀점수에 환원불가 오류 바닥이 있음.** 사진 전수(일부만 보지 말 것), 가상스테이징↔실제마감 구분, 뷰는 시티/리버 명확할 때만. 가격·통근·편의·주차·소음(자동)과 floor·detached(검증가능)는 신뢰. 사용자가 최종 검증자.

### 채점 서브에이전트 운용
- 입력 = `score_input.json`(floor/condition/vibe/micro/description/imgs) + `hood_input.json`(+analysis)
- amenity 필드는 manifest에서 자동 읽음 (commute 서브에이전트가 채운 값)
- 9건씩 배치, **백그라운드** 병렬 (`feedback_subagent_background`)
- 출력 = 각 항목 점수 + `_reason` 한 줄 + `_parts` 분해 리스트 + oneliner. 근거 없는 점수 금지
- 검증 = floor 교차검증 + UNSURE/충돌/이상치만 Claude 직접 사진 확인
- 점수차 1-2점은 동급
